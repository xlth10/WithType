# WithType · 主窗口进入动画 · 2026-10-12

**墨珠落纸，纸面展开，界面显露。** 延续“墨珠在宣纸上跳动”的视觉理念，以三颗对称墨珠和现有浅纸色完成约 700 ms 的一次性进入动画。

## 节奏

- 0–170 ms：中央墨珠从上方轻落并略微压扁，两侧同幅度起落。
- 105–490 ms：中央小纸面向四周舒展，最终覆盖整个主窗口。
- 196–630 ms：主界面淡入并完成轻微的位置收束，装饰墨珠与纸面渐隐。
- 700 ms：清理装饰层与进入状态；内容始终在 DOM 中，服务和设置读取独立运行。

整体保持左右对称。动画只改变 transform 与 opacity，无状态文字、声音或新的品牌素材；纸面与墨珠没有持续循环。

## 使用边界

- 初次进入主窗口播放；通过托盘“打开设置”或再次启动应用，从隐藏/最小化状态重新进入时播放。
- 已显示窗口的普通聚焦、页面导航、配置更新不重播。HUD 与提问/写法卡片不挂载这个组件。
- 装饰层 `pointer-events: none`、`aria-hidden`；点击或按键立即完成，原操作继续执行。窗口隐藏会结束当前动效。
- `prefers-reduced-motion: reduce` 时直接显示界面；偏好在播放期间改变也会结束动效。
- 原生事件与输入监听、计时器在卸载时释放；未完成的进入过程不会被重复打开事件重置。

实现：`src/ui/AppEntrance.jsx`、`src/main.jsx`、`src/styles.css` 与 `src-tauri/src/lib.rs` 的 `show_main()`。
