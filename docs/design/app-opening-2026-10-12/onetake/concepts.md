# OneTake 进入动画：概念比较

当前版 A 已原样保存到 `../preserved/`，主窗口的现有动画继续使用。新版本在独立实验预览中探索，选择核心画面后再写节拍与实现。

## 参考拆解

参考是现有 1400 ms 欢迎动画，去掉 GIF 为演示而增加的最终停留。OneTake `analyze_ref.py` 输出：0 次硬切，0 个爆发窗口，全画面平均差异阈值下静止比例 0.588，最长低能量段 0.83 s。其 320 px 光流读出的峰值为 187 px/帧、加权 t80 中位数 0.86。

这些是压缩后的画面指标，不是 CSS 动作的真实物理测量。中央墨珠占画面很小，全画面指标会高估静止；工具从画面读出的 smear 也不能证明原版具备真实快门模糊（原版没有多次快门采样）。参考联系表见 `reference-analysis/sheet_01.png`。

保留的规则：主体小、留白大、墨珠有重量、暖纸配深墨、欢迎语居中。新的探索点：让一个持续可见的元素从落纸动作一直承接到界面，不仅靠装饰层淡出交接。

## 三个不同的核心画面

| 概念 | 开场画面 | 贯穿元素与承接 | 材质、镜头与排除项 |
|---|---|---|---|
| 墨珠牵页 | 小墨珠悬在纸面，落点已有一段极短墨痕 | 墨珠落下带出墨线，墨线托起欢迎语，再延伸为界面的边界 | 使用产品暖纸和深墨；镜头只轻跟随落点并归位；无硬切、无粒子 |
| 随珠入纸 | 一颗近看的墨珠和纸纤维 | 同一镜头跟着墨珠落下，再从纸纹尺度连续拉远到欢迎语和界面 | 产品材质，强调尺度变化与屏幕锚点；无场景替换、无多页卡片 |
| 宣纸卷开 | 一条卷起的纸承着墨珠 | 落纸碰撞传到卷边，卷边舒展，同一纸面成为界面的背景 | 产品纸色与折面明暗；正面镜头略有深度；无文字逐字打出、无漂浮 UI 卡片 |

三者均保留 `Welcome, Ellen`。用户选择方向后再确定总时长、停顿与每个交接处。App 场景采用无声短时进入动作，保留点击/按键打断与减少动态路径，不套用宣传片的长度和配乐要求。
