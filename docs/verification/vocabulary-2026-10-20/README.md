# 双平台词库优化与验证 · 2026-10-20

Mac 分支：`codex/processing-macos-20261019`；Windows 分支：`codex/processing-windows-20261019`。两端分别保留原 ASR 与文字服务选择。共享词库代码按源文件哈希核对，平台实际能力由原生命令返回。

## 已实现

- 直接添加、编辑正确词，无需先编写误写；正确词提示与明确替换规则分开。
- 按文字、类型、手动/自动学习/导入来源筛选，25 条分页，维护原有替换语义。
- 自动学习提供当场撤销；只撤本次仍未被修改的记录。删除正确词后阻止自动学回，手动添加可恢复。
- CSV 文件或粘贴导入：预览有效、重复、无效和溢出行，再确认导入；限制 1 MiB、1,000 行。原有条目和手动规则均重新检查冲突。
- CSV 导出包含已保存词条和旧版手动规则；保留提示/替换语义，处理 BOM、引号、逗号和表格公式风险；原生版导出到下载目录且不覆盖文件。
- 保存总量 500 条，自动提示 30 条，单次 ASR 提示最多 100 个；明确展示保存量和下一次请求的选词/溢出情况。优先手动规则，再手动/导入词，最后自动词。
- 历史“纠正并记住”改为学习正确词提示；新教学不再隐式生成强制替换。既有替换继续保留。

## 平台差异

| 项目 | Mac | Windows |
| --- | --- | --- |
| ASR | 继续默认 Apple 本机识别；正确词传入 `contextualStrings` | 继续原有专有服务；没有猜测或新增未经验证的热词参数 |
| 外部输入框学词 | 新增 AX 观察，只在粘贴成功且原范围可验证后启动；需要辅助功能权限 | 保留 UIA 观察；修复焦点切换/超时会提交未稳定草稿的问题 |
| 稳定与退出 | 修改稳定 4 秒才提交；最长 60 秒；焦点、权限、范围或会话失效即丢弃草稿 | 共用同一稳定判断；焦点切换和期限结束不提交草稿 |
| 不支持的输入框 | 安全跳过，可通过历史纠正或直接加词 | 同样跳过，保留手动教学入口 |

自动学词只观察本次插入区间；不监听全局键盘，不修改外部输入框，不训练模型权重。

## 自动与交互验证

- 两端各自运行完整前端测试：**299 通过、0 失败、4 跳过**；跳过项需要 Windows PowerShell/运行环境。
- 词库相关用例 **45 项通过**，覆盖 CSV 格式/冲突/容量、来源保留、撤销竞态、旧替换兼容和提示预算。
- Mac 原生库 **89 项通过**，含观察区间、emoji UTF-16 边界、稳定/超时/焦点退出，以及受保护历史的阻塞回归。
- 两端前端生产构建、外观校验、diff 检查通过；Mac 发布包构建及 `codesign --verify --deep --strict` 通过。
- 浏览器实际操作：加词、大小写去重、拒绝纯数字、编辑、CSV 预览（2 有效/1 重复/1 无效）、确认导入、来源与搜索组合筛选、重载保留、CSV 实际下载。
- 下载 CSV 重新导入空词库，5 行全部有效；含两个旧手动替换，仍能将“快问三和千问三”变为“Qwen3和Qwen3”。
- 最终 Mac 包实际启动并进入词库页；原生加词和下载目录 CSV 导出通过。验收在本机加入产品名 `WithType`，没有改动文字模型或服务地址。

## Apple 真实识别对照

使用之前固定的 **4 条合成录音**，分别测试无词库、通过新增 API 加入正确词、删除词后三个条件，各 2 轮，共 **24 次真实 Apple 本机 ASR 调用**。未调用文字整理模型，也没有使用真实麦克风；这不是整体准确率或旧/新版本完整链路胜率。

| 观察项 | 无词库，两轮 | 加词，两轮 | 删除后，两轮 |
| --- | --- | --- | --- |
| 翟昀 | 翟云 | 翟昀 | 翟云 |
| 声笺 | 生间 | 声笺 | 生间 |
| 岑溪 | 晨曦 | 晨曦 | 晨曦 |
| 英文混说 | 仍有 WithType / Qwen / Apple Speech 误识别 | 未改善 | 与无词库一致 |
| 普通短句/数字改口对照 | 原始 ASR 输出有自己的格式/改口问题 | 输出与无词库相同 | 输出与无词库相同 |

词提示确实影响识别，但有边界：“项目名称叫声笺，别写成生煎”加词后识别为“项目名称叫声笺，别写成声笺”，对比词也被同化。该结果不能宣传为全句正确；应保留查看提示、删除词条及人工复核入口。

原始环境、音频哈希和全部输出在 [asr/](asr/)；复现脚本为 `scripts/benchmark/vocabulary-ab.mjs`，通过产品相同的 Apple bridge 请求词表，无服务密钥。

## Windows 验证边界

真实 Windows target 下，词库、UIA、投递、监控和 Tauri 命令注册的隔离交叉类型检查通过；历史异步接口与 DPAPI 分支的补充检查也通过。外围日志/原子存储在隔离 harness 中是编译替身，这不是完整产品构建或运行证据。

完整产品交叉检查在依赖 `ring` 编译阶段缺少 Windows SDK `assert.h`，没有到应用代码。用户目前没有 Windows 环境，专有 ASR 服务也没有真实地址，因此本轮未生成 Windows 安装包、未做 UIA/麦克风/投递运行验收或专有 ASR 效果测试。说明与日志保存在 [windows/](windows/)。

## 启动验收发现并修复的阻塞

首次运行新 Mac 包时，CUA 原生窗口读取连续超时。进程采样直接显示主线程阻塞于 `load_history → macos_crypto::master_key → SecKeychainFindGenericPassword → SecurityServer`，不是词库计算或渲染耗时。

历史三个命令改为后台异步执行，3 秒等待上限，单任务门控防止重复请求积累线程；系统返回太迟时放弃旧快照写入，已有密文和备份保留。不改变钥匙串 ACL、加密或授权策略。

修复后用相同新包启动与 CUA 读取路径复查：窗口可响应，词库加词/导出可用。本机系统钥匙串授权仍未完成，因此历史读取提示超时、录音保护性暂停；页面提供“重新载入应用”。未代为处理钥匙串授权，辅助功能权限也未授予，所以 **Mac 外部 App 自动学词尚未做实际运行验收**；其区间与稳定判断已由原生用例验证。
