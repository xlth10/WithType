## 已验证范围

- `npm test`：JS 逻辑、流水线、配置和取消回归。
- `npm run build`：React/Vite 生产构建。
- `cargo test --offline --lib` 与 `cargo check --offline`：当前 Mac Rust 分支。
- CPAL 音频、词汇观察、DPAPI 历史与注册表登录启动模块分别在独立最小工程中通过 `x86_64-pc-windows-msvc` 目标类型检查。此证据不覆盖完整 Tauri 链接与运行。

## 完成验收所需的外部条件

1. Windows 构建机或虚拟机具备 Windows SDK、C/C++ 工具链、Rust、Node.js 与 WebView2，执行 [Windows 验收步骤](windows-acceptance.md) 的全套构建和安装。
2. 配置真实 OpenAI 兼容 WAV ASR 与文字服务，运行可控音频对比：停顿、连续口述、末段失败、重试、取消、重启恢复和多轮 SSE。
3. 在目标应用中实测 UI Automation 观察、全局快捷键、剪贴板恢复、D 墨珠、登录启动与历史加密读取，记录产物及结果。
