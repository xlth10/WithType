# Typefree · 应用图标 v3

日期：2026-10-11。目标源码 `/Users/outsider/SEVB/Type`，基线 c84d53d；保留 2026-10-10 的四个前端修正文件。

产品：Windows 常驻语音写作工具，快捷键开始/结束口述，自定义 ASR 转写，可选文字整理、翻译、提问和技能；声音变成目标输入框里的文字。

用户认可原图标的墨珠与笔迹理念，希望提高 APP 图标适配性。本轮是图标的局部演进，沿用 Taste Skill 的品牌保留、轮廓和可读性原则；Taste 主版本面向营销页，因此不采用与图标无关的页面布局、图片和组件库约束。设计判断：安静的 Windows 写作工具，以墨与纸为语言，优先单一、集中、缩小时仍能辨认的轮廓。探索参数：形态变化 4、动效 0、密度 2。

一句话简报：把“声音凝成墨迹”压缩成能在 20–48px 辨认的一个记忆点。

当前资源：ink-v2，三颗递减墨珠、S 形曲线与月牙高光，暖灰绿底。缩小风险：笔迹薄处消失、上方小珠与高光碎化、主体分散、图标更接近插画。源文件与旧概念均保留。

必须传达：墨珠、写作、从口述到成稿的流动。避免：通用麦克风、盾牌或离线隐私承诺、字母与文字、细碎喷溅、长发丝曲线、装饰高光、小硬件图案、复制 Typefree 官方商标。

色彩：深墨 #282c27、暖纸 #f1f4eb；必要时用更深底与浅色负形增强任务栏识别。材料：平面或极浅深度，轮廓先于纹理。

成功标准：20px 主体不丢失；32px 内部空间仍分开；48px 不需要文字解释即可辨认；在浅色和深色桌面都有独立轮廓；单一主体，无须装饰细节支撑；Windows 多帧 ICO、网页及原生资源一致。

工作流：icon-designer 的 ChatGPT Images 2.0 工作流，实际使用内置 image_gen，工具未暴露具体模型版本。四个独立概念、逐一大图与缩小检查、选一个迭代后导出。项目为 Windows，将技能默认的 iOS 资产步骤调整为 Windows PNG/ICO；旧资源不覆盖，新增 ink-v3 并更新消费路径。
