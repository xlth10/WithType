# Windows 验收 · 2026-09-28

尚未执行 Windows 实机测试。下面给出确定步骤，避免把 Mac 的测试通过误认为 Windows 功能已经验收。

当前已知阻碍见 [目标完成度检查](goal-audit.md)：取消尚未传到原生粘贴，应先修复再验收“处理期间取消”的用例。

## 构建和启动

- 使用 README 的 GNU 或 MSVC 路径，检查 `typefree.exe`、WebView2Loader.dll、便携 ZIP、NSIS 与 MSI。
- 在没有开发工具目录加入 PATH 的普通终端解压启动，确认依赖完整。首次安装、首次授权麦克风、第二次启动都应正常。
- 退出后重新打开：模型配置、词库和凭据存在；不应把密钥写入 settings.json。

## 三个入口

- 记事本保持焦点，Ctrl+Alt+Space 按一次开始，松开仍录音；再次按下结束并输入结果。
- 录音中按提问键不结束当前口述；同一按键快速再按、授权弹窗期间结束/取消，不得留下麦克风占用。
- 提问只显示回答卡片；第三键的翻译/技能/命令按设置执行。处理期间取消，迟到结果不得再上屏。
- 分别在 UIA 准备、剪贴板等待阶段取消，确认原生后端未继续发 Ctrl+V；此用例当前有已知缺口。强制粘贴失败时，应退出处理状态，历史保留最终正文供复制，并尝试恢复先前文本剪贴板。
- 修改快捷键，尝试重复组合和被别的程序占用的键；失败应保留旧键。关闭主窗后托盘和快捷键仍可用。

## 墨珠 HUD

- 以实际176×54大小覆盖记事本，静音无波动，低音量时两侧也可见，任何时刻侧珠低于中央。
- 开口/停顿/识别/完成的切换连续；启用系统减少动画后处理状态不持续游动。
- 125%、150%、200%显示缩放、双显示器、取消和错误状态均无裁切。

## 自动学习

先用可控制转写文本的测试 ASR 或真实误识别，测试后在词库删除测试规则。

1. 转写输出「明天联系徐向开会。」并粘贴到记事本，在同一输入框把「徐向」改为「徐翔」，停留4秒。
2. 个人词库应只有候选「徐向 → 徐翔」（1/2），未正式生效。
3. 再做一次独立口述、同样纠正；应进入已记住。重启应用，下一次「徐向」应本地改为「徐翔」。
4. 删除该规则；后续相同纠正不再自动学入。历史记录的明确教学仍可以手动恢复。
5. 「周四→周三」「他的→她的」「共5次→共4次」、改标点、删除/整句重写不应自动学入。
6. 粘贴前后有原有文字，只改范围外文字不学习；焦点切换、密码框、读取失败、超长内容和重复不明区间都跳过。
7. 连续两次口述，新一轮也能进入学习；取消观察后旧线程不得发出词条。
8. 关闭学习开关后不新增候选，原有词仍生效；关闭自动输入或使用翻译/提问不观察输入框。
9. 浏览器 textarea/contenteditable、VS Code 和常用聊天编辑框各测试一轮。UI Automation 不可读时，历史页「纠正并记住」仍应可用。
10. 配置目录不可写时应提示未保存，不得显示“已记住”。不保存输入框全文。
