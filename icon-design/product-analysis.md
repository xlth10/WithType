# Typefree Windows 图标分析 · 2026-10-10

## 产品

面向经常写邮件、笔记、会议纪要和需求的 Windows 用户。核心操作是开口说话，结束后让内容成为文字；随便问与技能提供辅助表达。希望传达安静、轻盈、可控的表达体验。

## 图标简报

让墨珠从声音的节奏落成一笔文字；在 20–48 px 仍能认出，与当前纸色界面和墨珠 HUD 对齐。

## 语义与颜色

- 语义：墨珠、停顿、落笔、整理后的文字。保持一个主要轮廓。
- 颜色：深墨 #282c27、暖纸 #f1f4eb、灰墨 #676b63，辅以很少量的灰绿 #dfe3d7。
- 必须：小尺寸轮廓明确，明暗背景均可识别；应用侧栏、问答卡片、窗口标题栏、托盘和安装包使用同一标记。
- 避免：通用麦克风、旧青绿色气泡、多重细节、文字缩写、发光与玻璃渐变，以及只有一个孤立圆点。

## 技术约束

Windows 产品，前端已有 SVG 图标与可复现 Pillow 导出脚本。以生成图片探索方向，再用可编辑的几何母版落地。保留旧资产，新版本用 v2 名称。导出 SVG、PNG、包含 16/24/32/48/64/128/256 帧的 ICO；本项目不需要 iOS 资产。

ICO 用于 Tauri/NSIS、窗口和托盘，避免依赖本机会被 DLP 加密的 PNG 字节。前端用 SVG，图标不会依赖在线图片地址。

## 成功标准

20 px 能看清主要轮廓；32 px 能看出声音到文字的关系；48 px 保持圆角、留白和清晰边缘。100%–200% 显示缩放下均有对应 ICO 帧；浅色纸面和深色任务栏都能辨认。

## 用户指定参考后的修订

最终采用用户上传的三颗墨珠与流动笔迹图像：大珠在左下，小珠沿右上前行，S 形笔迹表达声音落字。去除飞溅、纹理与复杂高光，以单个主珠月牙保留墨珠材质暗示。四个初始方向和五珠修订保留为探索证据。
