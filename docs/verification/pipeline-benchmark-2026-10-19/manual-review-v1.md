# v1 人工复核与规则漏报

自动检查保持原规则；本文件补充人工语义判断，不回写或抬高自动分数。所有文本来自固定合成语音，原始结果未覆盖。

| 情况 | 复核 |
|---|---|
| number-correction 优化第 2 轮 | 最终金额 10200、数量20正确；“不是12000”显式否定旧值。none 断言把它算失败；语义值正确，简洁收敛仍不彻底。 |
| long-withdrawal 两端 | 2:00 是有效两点时间格式，time断言漏报；失败样例与“只”已经在ASR丢失，不能据此把整例改成通过。 |
| proper-names 优化两轮 | 翟昀、声笺改善，岑溪仍错；整例失败不能掩盖两个词的局部改善。 |
| paragraph-fidelity 两端 | 自动检查通过，但ASR漏掉Mac且“专名”识成“专门”，人工不能据此认定全文保真。 |
| question-is-text 优化 | 保留问题句，去掉“我想发给同事，请保留问法”元叙述；该删减是否符合默认整理力度需产品判断。 |
