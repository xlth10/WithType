# Mac 处理链路实测：最终 v2 结果

当前版本在同一组 16 条固定合成语音上完成两轮真实 Apple 本机 ASR + 现有 deepseek-flash；明确改口的日期、时间、金额在两轮都正确收敛。部分专名因 Apple 热词提示改善。残余主要集中于本组合成素材的 ASR 误识、漏词，以及局部自动评分的表达覆盖不足；没有证据支持“已经解决全部保真问题”。

| 版本 | 轮次 | 完成 | 局部自动检查通过 | 文件提交到完整成稿 p50 | p95 |
|---|---:|---:|---:|---:|---:|
| 基线 534b3d7 | 1 | 16/16 | 8/16 | 3489 ms | 11578 ms |
| 基线 534b3d7 | 2 | 16/16 | 8/16 | 1960 ms | 5566 ms |
| 最终 v2 | 1 | 16/16 | 11/16 | 1722 ms | 5936 ms |

基线也显式选择 Apple Speech，以保持 ASR 模型相同；这不是旧默认云 ASR 与新 Apple ASR 的模型优劣对比。固定音频、口述清单和原始局部评分规则相同；v1 中间版本的四轮数据也完整保留，未覆盖。16 条小样本的局部检查通过数不是总体准确率。未做足够的随机化与重复次数，且服务等待存在波动，因此时间数据只描述这些运行，不能宣称稳定提速。

## 文字整理隔离测试

额外执行了 8 条“固定参考文本 → 实际产品路由 → 真实 deepseek-flash”用例，包括日期、金额、否定、强调、条件承诺和原话引用；局部检查 8/8 通过。关键人工复核：

- “今天给预览，正式版本周五交付”的两种期限都保留。
- “如果测试通过、争取周五、没有批准上线”仍是有条件且未批准。
- 明确禁止自动发送的强调保留，没有改成发送授权。
- 英文原话引用的 Wednesday 与 Thursday 都保留，没有把对历史原话的引用当新安排。

最终冻结源码又单独执行5条实际文字模型烟测：短改口“明天四点开会。”、日期“周四发版。”、三种撤回均“明天暂停发版。”，局部检查5/5通过；完整最终文件指纹独立保存。

另执行 3 条带有效前文的撤回参考文本：“前面不要了”“刚才不用了”“以上撤回，只保留最后”，最终都真实返回“明天暂停发版。”，旧安排未残留。这只验证最终全文进入真实文字模型后的行为。录音中增量缓存是否正确失效另由产品单元/集成测试验证，本轮没有做实际麦克风、增量录音与上屏验收。

## 必须保留的残余问题

| 用例 | 剩余问题与人工判断 |
|---|---|
| negative-deadline | Apple 把“预览”识为“玉兰”，影响正式版/预览版的含义；后续模型沿用错误文字。参考文本正确时，模型能保留预览今天、正式周五。 |
| proper-names | 翟云→翟昀、生间→声笺改善；岑溪仍为晨曦，整例未通过。 |
| mixed-identifiers | WithType、Qwen ASR、Apple Speech 在合成中英语音中仍被误识，热词未解决。 |
| long-withdrawal | 最终部门、周四14点、20份已收敛；2:00是有效时间格式但局部规则未覆盖。同时ASR丢失“样例”“只”，所以不能把整例人工抬成通过。 |
| polish-fidelity | Windows 被识成韵达，润色不能可靠凭空还原。 |
| paragraph-fidelity | 自动检查通过仍不代表全文保真：ASR漏掉Mac、把“专名”识成“专门”，需要严格人工复核。 |

v1 第二轮预算成稿“不是12,000”是明确否定旧值，局部 none 规则过严；已在 [人工复核](manual-review-v1.md) 单列，保留原分数。热词的局部改善和未改善都要保留，不能仅报告整例得分。

## 口径与复验

- 主延迟指标是**固定音频文件提交到完整成稿**，没有测录音中预识别的重叠收益，不能叫实机松手到上屏。
- 复制/粘贴由输出收集器接管；没有测 WithType 麦克风、快捷键、焦点捕获、UIA 或真实输入框投递。
- Apple ASR 由独立授权、LaunchServices 启动的 probe 复用产品原生桥；文字服务复用产品 Rust 客户端及既有系统凭据库。没有记录密钥。
- 文本主模型与快模型都保持 deepseek-flash、温度0.2；关闭流式预览和录音中增量整理以隔离完整成稿。
- v1 原始 ASR serviceCalls.model 记录的是历史配置字符串 Qwen3，实际调用由 provider=apple、组合适配器与 Apple health 共同确认。v2 已改为记录实际 Apple on-device Speech，旧 JSONL 未回写。
- 合成语音不能代表真人口音、噪声、麦克风和英文发音。Windows 没有设备及真实服务地址，本轮按用户指示暂缓服务与客户端实测。
