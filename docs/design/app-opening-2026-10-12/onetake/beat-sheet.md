# B · 随珠入纸 · 节拍表

用户于 2026-10-12 选择第二个概念：镜头跟随一颗墨珠落下，近看纸纹，再连续拉远显露欢迎语与完整界面。

总长 2.4 s，无声音。它是 App 的进入动画候选，不采用 10–30 s 宣传片的时长和配乐。A 版 1.4 s 与原源码快照继续保留，B 版独立预览。

| 时间 / s | 画面与动作 | 静止的部分 | 承接到下一段的元素 |
|---|---|---|---|
| 0–0.10 | 近看悬空墨珠、下方落影和宣纸纤维 | 镜头与墨珠暂歇 | 同一墨珠、落点、纸面 |
| 0.10–0.50 | 墨珠向纸面落下，镜头提前跟到落点并轻推近 | 纸纹在世界坐标中固定 | 墨珠接触同一纸面 |
| 0.50–0.84 | 墨珠压扁再轻弹，落影收放；淡墨渗入纤维，两侧墨珠分出 | 镜头在落点附近停住 | 同一墨珠和吸墨痕迹 |
| 0.84–1.44 | 一次连续拉远，纤维由近景退到日常尺度；欢迎语从纸面升起 | 同一纸面；没有切换场景 | 镜头、墨珠、欢迎语和背景纸面 |
| 1.44–1.84 | 五颗墨珠与 Welcome, Ellen 居中停留 | 镜头、墨珠、纸纹与欢迎语完全静止 | 中央落点作为显露界面的起点 |
| 1.84–1.98 | 欢迎语收住，墨珠仍保持落点 | 镜头与纸面 | 同一中央墨珠与落点 |
| 1.98–2.40 | 同一纸面从落点打开，显露实际 React 界面；墨迹退去 | 镜头已归位，最终布局不移动 | 同一个世界层与真实界面，结束后直接操作 |

最长段 0.60 s / 最短段 0.10 s = 6，避免匀速逐项出场。相机只在主体需要时运动，欢迎语停留期间不漂移。

## 动作选择

- `OM.camera` / `OM.view`：屏幕中央锚点、跟随、微距与连续拉远，缩放采用库的对数插值。
- `OM.hop` / `OM.impact`：落纸、低幅回弹和压扁恢复。
- `OM.gather`：侧墨珠从落点镜像分出。
- `OM.wordRise`：欢迎语从纸面轻升，使用库弹簧；静止段将已收敛值固定为最终值。
- `OM.iris`：落点打开实际界面，避免 unrelated scenes 的淡入替换。

库的 camera、hop、maskRise、morphRect 动作联系表已查看；没有使用模板的标题卡、清单或宣传片故事。采用产品自己的纸色 #f8f7ef、深墨 #282c27 与现有 Noto Sans 字体，纸纹是固定种子的细纤维，不是粒子。所有动画值来自绝对时间，截图预览只通过 `?t=` 驱动相同合成。

## 验证边界

OneTake 的完整宣传片 oracle 的最后 1.2 s 免验、至少 1 s 静止段等阈值不能直接证明一个 2.4 s 的 App 动画合格。会同时记录实际 DOM 的连续身份、每个节拍交接、静止段、画面边界、确定性与减少动态，不把 0 个自动边界的 PASS 当作证据。渲染预览采用 1080p30 草稿与真实快门采样；没有做未验收的 4K 成片。
