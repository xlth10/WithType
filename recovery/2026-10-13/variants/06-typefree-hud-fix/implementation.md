# HUD 改进与复验 · 2026-10-11

修改位置：最新版 `/Users/outsider/SEVB/Type`，基线 c84d53d 上的当前工作区。对应 [HUD 专项补审](../report.md)。

本次按用户明确的设计要求调整：HUD 不显示“口述中”“整理中”等状态文字，保留“墨珠在宣纸上跳动”的语言及左右镜像结构。原报告中“显示短状态文案”的建议由此替换为墨珠反馈与隐藏的辅助功能状态播报。

## 墨珠反馈

| 状态 | 可见反馈 |
| --- | --- |
| 录音 | 中心墨珠与两侧镜像墨珠随录音电平变化；静音收成稳定中心墨点。 |
| 处理 | 三珠持续、对称地收拢与舒展，与静音录音形态不同。 |
| 完成 | 两侧墨珠收拢，中心一珠落定并出现细环。 |
| 失败 | 墨珠分成左右两瓣后停住，沿用既有错误色，形状本身也能区分失败。 |

状态几何只应用于 HUD，主窗口的 VoiceMotion 使用原有墨珠效果。减少动态效果时停止处理中循环，处理、完成、失败仍保留各自静态形态，录音电平反馈保留。

## 审查项落实

- **H1**：移除可见状态文案，避免文案偏移和两份映射互相矛盾。隐藏播报复用 `statusLabel`，支持识别、判断口述类型、处理文字、回答、翻译；浏览器预览新增 `phase/intent` 参数以便逐项复验。各处理阶段共用处理中的墨珠形态，不要求用户辨认模型内部阶段。
- **H2**：加入视觉隐藏的 `role=status`、`aria-live=polite`、`aria-atomic=true`。仅离散状态或阶段改变更新文案，动画画布保持 `aria-hidden`，不逐帧播报。
- **H3**：移除悬停与聚焦时降低墨珠透明度的规则。中央 76×26 画布保持居中；录音时两端分别显示结束、取消按钮，按钮均为 34×34。其他状态保留两端槽位，取消或关闭按钮位于右端，不推动墨珠。触摸环境直接显示适用按钮。

浏览器预览支持结束进入处理、取消返回待机，便于复验；原生环境仍发送既有 `stop-recording` / `cancel-recording` 事件。

- `npm run build`：通过；Vite 仍提示主 JS 包超过 500 kB，本次未引入依赖。
- `git -c core.whitespace=cr-at-eol diff --check`：通过。
- 最新源码的浏览器预览：HUD 176×54，画布中心与 HUD 中心同为 x=120；录音按钮中心 x=62、178，与中心镜像。无 `.hud-status`；播报节点为 1×1 且裁剪隐藏。
- 验证录音、静音、处理、完成、失败画面；鼠标移入时按钮可见且画布透明度仍为 1；聚焦结束按钮出现焦点环且中央墨珠保留。
- 点击预览结束按钮，状态变为处理、播报“正在识别”、操作名变为“取消处理”；点击取消返回待机。逐项检查判断、回答、翻译阶段的播报。

截图来自 240×160 浏览器视口，按 HUD 与留白裁剪为 196×74 CSS 像素，属于前端证据。本次没有运行真实麦克风、Windows 原生窗口或屏幕阅读器；没有改动原生窗口尺寸、置顶、DPI、焦点保持及快捷键逻辑。原生 HUD 保持 `focusable:false`，浏览器聚焦验证不代表原生窗口接受 Tab 聚焦。
