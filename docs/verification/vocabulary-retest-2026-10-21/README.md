## 发现并修复：历史已恢复，后台仍可能失败

旧包实际操作：历史超时后点击“重新载入应用”，历史内容成功读出，错误横幅消失，但放大窗口后顶栏仍显示“输入暂不可用”。点击原有“恢复”入口可以重新初始化，证明普通重载没有完成后台恢复。

根因：历史失败将后台置为 `Failed`；原 `page_loading` 只处理 `Ready`，新前端读到 `Failed` 后拒绝就绪。历史加载成功并不能解除这一状态。

修复将页面重载转移放入实际使用的 `Machine::page_loading`：从 `Ready` 或 `Failed` 创建新 `Starting` 代次，再等待前端资源握手。睡眠、锁屏、暂停和停止状态不被重载解除，旧任务/命令不会恢复；旧历史超时状态消息被替换。

修改仅为 `src-tauri/src/background.rs` 与 `src-tauri/src/background/state.rs`。红/绿测试、完整原生测试及构建日志在 [logs/](logs/)。
