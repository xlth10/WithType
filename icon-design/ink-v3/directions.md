# 当前四方向

用户的“墨珠在宣纸上跳动”修订后，使用内置 image_gen 独立生成四个方向：

- A 三珠跳落：不同大小的三个圆珠形成紧凑弧线，平面、无连接轨迹。
- B 落点弧：一个圆珠加一个厚实开放落点弧，表现刚刚回弹。
- C 墨珠节奏：主珠悬空、两颗侧珠起落，轻微接触印，尺寸不对称。
- D 单珠回弹：圆珠悬在短宽椭圆落点上方，集中为上下两形。

共同要求：宣纸浅底、圆润深墨、18%左右留白、不使用文字与细碎装饰。C 在产品契合和小尺寸区分上胜出，再降低纸纹与球面噪声。

精确提示词和原稿见 exploration/rice-paper-prompts.json、exploration/concepts/，评分见 exploration/rice-paper-review.md。用户修订前的深色底/筆迹方向仅保留探索证据，不使用。
