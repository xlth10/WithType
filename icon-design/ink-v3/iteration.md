# 修订与成稿

用户于 2026-10-11 明确“墨珠在宣纸上跳动”。初期负形笔迹方向撤回。最终选择第二轮 C：一颗主珠腾起、两颗侧珠在不同落点，浅宣纸作为固定底。

第一轮 C 纸纤维、球面颗粒和阴影较重；image_gen 修订减轻纸纹与高光，保留三珠起落。随后生成圆角透明边界，但栅格产物边界存在白色碎片，不集成。生成图原样保留为概念证据，不用程序擦改生成图。

生产母版根据已选概念重建本项目的圆珠、落点和宣纸几何，以版本化脚本同时输出 SVG/PNG/ICO。主体三珠位置与大小统一；不将栅格产物假称为原生矢量。16–32px 省去纤维与接触印；48px 以上保留克制的落点；128px 以上才加入极淡的纸纤维。

成稿再评分：识别 5、产品契合 5、轮廓 5、小尺寸 5、平台适配 5、区分度 4、生产风险 5。分数是设计判断，不是用户实验。
