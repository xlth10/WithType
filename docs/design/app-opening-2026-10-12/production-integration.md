# 正式入口接入 · 2026-10-13

用户确认初始圆形墨珠、落纸、湿墨成字符合预期，随后指定把动画和欢迎语合入 `projects/15-withtype` 正式版本。原 `SEVB/Type` 仅从废纸篓复制作为本次实现和历史证据的来源，没有整体覆盖正式版的语音输入逻辑。

正式入口与 C 交互预览共用 `src/ui/inkWelcome.js` 的 Canvas 绘制器，以及同一套运动数值和播放控制。时间仍为 3.6 秒：0–0.70 秒悬停及加速落纸，0.70–1.16 秒铺开湿墨，1.16–2.00 秒墨体收拢成字，2.00–2.70 秒问候静止，2.70–3.60 秒拉远显露界面。墨画布采样为逻辑尺寸的 3 倍，纸纹为 2 倍；使用现有离线 Noto Sans SC 字体，字重 420。

「外观」支持编辑完整欢迎语、预览和恢复默认。默认 `Welcome, Ellen`，例如可改为 `Welcome，outsider`。最多 40 个 Unicode 字符；长文字缩小字号，保持镜头和时间轴。配置读取成功与字体就绪后才开始播放。配置或技能读取失败会直接显露界面和原有错误提示，避免被进入动画遮住；输入资源的就绪保护保持不变。

只有主窗口使用该入口，HUD 和结果卡片保留原渲染。点击或按键可跳过；Tab 跳过并把焦点交给主界面按钮。减少动态、后台隐藏、尺寸改变会结束当前播放；托盘重新打开隐藏或最小化的主窗口时重播，普通聚焦不重播。组件销毁会取消 RAF，释放画布与字形场。

## 验证范围

运动时间轴、纸纹随机序列、播放完成/重播/跳过/减少动态/迟到帧、欢迎语归一化与持久化均有单测。生产外观校验纳入进入组件、绘制器、运动模块、播放器、样式与欢迎语模块的源码哈希，并核验构建中的离线字体与原文件一致。

本轮测试与浏览器核对的最终结果见 [验证记录](production-checks.json)。原始基线记录保持原样；构建日志不作为必须提交的文件。

用户明确选择「暂时不验证，代码通过测试即可」，因此本轮没有在 Windows/WebView2 实机启动 EXE，也没有宣称 Windows 像素一比一已经验收。Windows 的实际 DPI、字形光栅化、流畅度、冷启动和重开仍属于后续实机核验。
