# 产品与当前图标简报

Windows 常驻语音写作工具：通过快捷键口述、识别、整理，文字进入目标输入框；也提供提问、翻译与技能。视觉语言是墨与纸，情绪为安静、轻盈、可控。

用户于 2026-10-11 明确当前图标理念：“墨珠在宣纸上跳动”。此次以此为准：浅宣纸是固定画布，圆润墨珠是主角，空间位置、大小节奏与克制的接触印表达起落。

必须保留墨珠和宣纸；必须适配 20–48px、小任务栏与暗浅背景。避免字母、通用麦克风、长细轨迹、月牙高光、喷溅和重纹理。大主珠与两颗侧珠形成紧凑图形；深墨 #282c27、宣纸 #f5f5ed。

技术：Windows 图标需要多尺寸 RGBA PNG 与多帧 ICO；前端共用 SVG。版本化 v3 保留 v2。现有源代码图标系统允许在图像概念选定后重建干净几何，不直接把生成图转存成所谓 SVG。透明角和不透明纸面明确验证。

成功标准：20px 三珠仍分开，32px 圆润主体与间隔清楚，48px 识别不依赖纤维；深色和浅色背景均有独立纸面轮廓。实际 Windows 合成另行验收。
